# Paintings

One series for the new site, generated on the Lay2 ComfyUI (Qwen-Image 2.1 Q6_K GGUF, euler / simple, 25 steps, cfg 1), 1664 × 1040, saved as WebP.

The style is an Enlightenment-era oil painting in the manner of Joseph Wright of Derby and Chardin, about 1785. The light is warm, and scholars wear indigo silk banyans. Japanese touches are Imari porcelain and lacquer. The left third of each painting is kept quiet for type. Every painting except the homepage hides one modern object painted in period technique.
